LinkedIn search URL breakdown

Common query parameters you may see in LinkedIn job search URLs and what they mean:

  • currentJobId=4184090151 — Specifies a job currently being viewed. Changing/removing it does not affect the search results.
  • distance=25 — Search radius in miles. Change to distance=50 to search within 50 miles.
  • f_TPR=r3600 — Recency filter. r3600 = last hour. Common values: r86400 (24h), r604800 (7 days), r2592000 (30 days).
  • geoId=103644278 — Geographic identifier for the region (used internally by LinkedIn). Replace with the geoId for your desired area.
  • keywords=senior%20operations%20manager — Search keywords (URL-encoded).
  • location=United%20States — Human-readable location string in the URL.
  • origin=JOB_SEARCH_PAGE_JOB_FILTER — Indicates the UI origin; safe to ignore for scraping.
  • sortBy=R — Sort mode: R = relevance, DD = date posted.

Tip: the scraper accepts a --time-range flag which maps to f_TPR=r{seconds} (for example --time-range 24h → f_TPR=r86400).
